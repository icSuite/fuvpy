# Vault Conventions

Last reviewed: 2026-09-01

- `01_Project/Project Brief.md` owns stable purpose and scope.
- `01_Project/Current State.md` owns verified current state.
- `02_Algorithm/` owns durable scientific and numerical interpretation.
- `03_Decisions/Decision Log.md` records decisions with rationale.
- `04_Sessions/` is optional dated history, not a running transcript.
- `05_Handoff/Handoff - Latest.md` owns the next actionable state and the
  portfolio synchronization boundary.

Use repository evidence before memory. Label unverified claims as hypotheses.
Replace stale live state instead of appending a diary.
